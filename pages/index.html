Plain-English release notes for the knobs in your repo

knoblog walks a git history, pulls every parameter, gain, threshold, flag and config default out of each commit, and writes down exactly what changed, e.g. inflation_radius 0.55 → 0.7 (27% higher), with the commit link. Output: a static site, Atom, a JSON feed of structured changes, and X-ready post text (never posted).

Supports ROS 2 parameter YAML, PX4 module.yaml and PARAM_DEFINE_*, ArduPilot AP_Param tables, C/C++ #define/constexpr, Python/Rust/JVM constants, and YAML/JSON/TOML.
